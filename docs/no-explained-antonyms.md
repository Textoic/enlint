# No Explained Antonyms

Phrases that follow the pattern "not (adjective/adverb/verb)". Examples:

1. not sure => unsure
2. not unlucky => lucky
3. not forget => remember
4. not fresh => stale

Negative patterns with ambiguous words or gradable adjectives are not included. Examples of cases we DO NOT IDENTIFY AS PROBLEMS:

1. not freezing => hot? barely cold? scorching? lukewarm?
2. not leave => take? stay? continue?

Words that are already lexicalized negatives are left alone too, so "not illegal", "not amoral" and "not impossible" are not flagged.
