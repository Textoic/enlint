# No Noun Clusters

This is a direct implementation of ASD-STE100's rule 2.1, which states that you should "Write noun clusters of no more than three words". Although this rule is meant for technical environments where clarity is imperative, any text can benefit from avoiding long chains of nouns. Examples:

1. Stainless steel protection strips.
2. Runway light connection resistance calibration.

Four words is the first violation, so "steel protection strips" passes and "stainless steel protection strips" does not.

This rule is off by default and has to be enabled in a config.
