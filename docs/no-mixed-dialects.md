# No Mixed Dialects

Some words vary depending on the English dialect you use. The differences might be small (British colour vs. American color) or change the whole word (British aubergine vs. American eggplant). In any case, you should decide on a dialect and use the correct version of each word for that dialect.

1. (Preferring American English) car park => parking lot
2. (Preferring British English) neighbor => neighbour

This rule is off by default. Turn it on in a config and set `locale` to the dialect you want.

Note: If you want to follow the ASD-STE100, rule 1.14 instructs you to use the American English spelling if possible.
