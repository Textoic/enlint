# No Passives

This rule will only identify full passive sentences, i.e. passives where the passive agent is present. To see the difference, consider these two cases:

1. Stories were told by the people around the campfire (Full passive. It has the passive agent "by people").
2. The fields were covered in snow (Partial passive. It has no passive agent)

Textoic will offer a replacement for these full passives with the sentence already in the active. Since this is an automatic process, we recommend that you check the replacement for any errors. Other examples:

1. The piano is played by John => John plays the piano
2. Spain was visited by many tourists => Many tourists visited Spain

A "by" phrase is not always an agent. In "the work is done by Friday", "sales
are doubled by 2030" and "the description is done by paragraph six" it is a
deadline or a place in the text, and turning the sentence around would say the
date did the work. Those are read as partial passives and left alone.
